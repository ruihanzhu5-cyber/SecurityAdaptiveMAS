## 本次真实实验发生了什么

用户确认费用后，计划按 B1→B0→A0→A1 执行四组。实际只启动了无攻击的 B1：Coordinator 成功取得一次 DeepSeek Flash 回答，并调用真实邮件读取工具。之后风险分析请求返回 HTTP 400，按首个接线失败即停止的要求，后续三组未运行。

错误原因已定位：风险请求要求 JSON mode，但提示词没有 API 要求的 json 一词。这是项目请求契约问题，不能说成 DeepSeek 超时或模型受到攻击。问题已上报为 [Issue #3](https://github.com/ruihanzhu5-cyber/SecurityAdaptiveMAS/issues/3)，本次未修复、未重跑。
